Uruk — a multi-tenant CMS

A website is
data, not code.

Uruk composes entire sites from rows in Postgres — element trees rendered to HTML, cached until the data changes, edited by people and AI agents over the same API. No templates to commit. No build to run. No deploy to wait for.

sh — get running
$ git clone https://github.com/Galaktis/uruk && cd uruk
$ docker compose up
# http://localhost:8000 → this site, served from rows
