Architecture

How a request becomes a page

One deployment, one Postgres, many sites. Tenant routing runs first on every request: the Host header resolves to a Domain row, the connection's search_path switches to that tenant's schema, and from that moment every query — pages, elements, users, assets — can only see one site's world.

The two right-hand stages almost never run. Computed HTML is cached per page, and a dependency graph keeps that cache honest — which is the part of a CMS that is usually wrong, and the part Uruk treats as the core of the design.
