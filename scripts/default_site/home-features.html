What the city provides

One deployment, many sites

A single Uruk serves any number of tenants. Each one is a walled district: its own schema, its own users, its own everything.

A schema per tenant

The Host header picks the tenant; the connection's search_path does the isolation. Users, content, and tokens never share tables across sites.

Exact invalidation

The hard problem, solved with a dependency graph: every render records what it read, so one edit evicts precisely the affected pages — nothing more, nothing stale.

Agents are editors

The first admin client is an MCP server, not a dashboard. An agent authenticates as a tenant user and can do exactly what that user's permissions allow.

Sites that travel

Every row has a UUIDv7 key, so a whole site exports as one JSON archive and restores anywhere without collisions. This very site ships as one.

Assets live in the DB

The CSS styling this page is a row, served at a content-hashed URL with an immutable year-long cache. Even the fonts are rows. Few files, full speed.

No commit-to-create

A new site is an API call, not a repository. The only committed code is the generic renderer library every tenant shares — everything else is rows.
