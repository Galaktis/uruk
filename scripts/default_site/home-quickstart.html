Founding a city

Running in one command

Docker is the only requirement. On first start the app container migrates every schema and raises the default tenant — the site you are reading now — next to a remote MCP endpoint. Then hand an agent a token, let it build, review the draft in the Studio, and publish.

The full quickstart, including MCP setup
sh — from zero to served
$ git clone https://github.com/Galaktis/uruk && cd uruk
$ docker compose up -d
app   migrating public + tenant schemas, seeding the default site…
app   Listening at: http://0.0.0.0:8000
mcp   Listening at: http://0.0.0.0:8001  (/mcp)
# any hostname you point at it now serves this site
