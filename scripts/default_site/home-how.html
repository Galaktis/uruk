From tablet to page

Three moves, same as 3200 BC

A scribe pressed records into clay; a renderer presses rows into HTML. The pipeline is short enough to hold in your head.

01 · WRITE

Rows, not files

Every block on this page is an Element row — a kind, JSON parameters, content, and a parent. Pages are rows too, arranged in a URL tree.

{
  "kind": "heading",
  "content": "A website is data",
  "parameters": { "level": 1 },
  "parent_id": "0198…root"
}
02 · RENDER

The tree becomes HTML

A small library of committed renderers walks the element tree. Text is escaped by default; there are no per-site templates anywhere.

# the only committed "template"
@register("heading")
def heading(el, children, ctx):
    return format_html(
        "<h{0}>{1}</h{0}>",
        el.parameters["level"], el.content)
03 · CACHE

Cached until a row changes

Each render records which elements it touched. Saving one element evicts exactly the pages that used it — a shared header invalidates everywhere at once.
